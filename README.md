# Replication Materials: AI Compute Import Dependence and Dollar Invoicing

Replication code for *"AI Compute Import Dependence and Dollar Invoicing: Cross-Country Evidence for a Compute-Dollar Association"* (Uddin, 2026). Preprint: [SSRN 7003871](https://ssrn.com/abstract=7003871).

## Contents
- `compute_dollar_pipeline.R` — full R pipeline: builds the country panel and produces all tables, including the safe-asset simulation.
- `data/panels/master_panel.csv` — merged analysis panel produced by the pipeline.
- `output/tables/Table8_safe_asset_simulation.csv` — safe-asset simulation output.

## Data sources
Raw inputs are public but are not redistributed here; download them from the original providers:
IMF Portfolio Investment Positions and COFER (data.imf.org), UN Comtrade (comtradeplus.un.org), AidData v3.0 (aiddata.org), World Bank WDI (databank.worldbank.org), Chinn-Ito Index (web.pdx.edu/~ito), and dollar invoicing data from Boz et al. (2025), IMF Working Paper No. 2025/178.
